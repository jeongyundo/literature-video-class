질문

공간에 대한 필자의 관점은 무엇인가? (교과서 p.223 학습 활동 2)

글의 답

공간은 법규나 겉모습만 챙기는 관리가 아니라, 사용자(특히 사회적 약자)를 배려하여 계획하고 관심을 두고 매일 돌보고 가꾸어야 한다. 그래야 안전하고 편안한 공간과 함께 사는 공동체가 생기고, 새것과 기존 것이 조화를 이룬 더 좋은 도시가 된다. (1~2문단 개념 → 3~7문단)

  1. 1 · 1~2문단개념가꿈·돌봄 ↔ 관리
  2. 2 · 3~4문단문제와 사례꾸미기에 열중 → 수원 버스 승강장
  3. 3 · 5문단주장매일 돌보고 가꾸기
  4. 4 · 6~7문단결론공동체 · 새것과 기존 것의 조화
11~2문단문단 탐험: 개념: 가꿈·돌봄 ↔ 관리

개념: 가꿈·돌봄 ↔ 관리

하는 일: 디자인의 의미를 밝히고, 가꿈과 돌봄을 정의해 공통 의미를 이끌어 낸 뒤 단순한 관리와 대조함

큰 틀 요약

  • 우리는 도시·건축을 디자인함 — 자기가 사는 집도, 사회적 약자를 위한 공간도
  • 디자인 = 어떤 목적이나 의도를 가지고 대상이나 공간을 가꾸는 것, 사람-공간-건축-도시-자연-마음을 연결하는 작업
  • 가꿈 = 식물이나 기르는 장소를 손질하고 보살핌(좋은 상태로 꾸려 감) / 돌봄 = 관심 있게 보살핌 → 공통: 정성을 기울여 보호하며 관심을 두고 지속해서 보살피는 일(교과서 p.219 날개 질문의 답)
  • 관리 = 배려·공감 없이 최소한의 법적 요건만 갖춰 겉모습을 꾸미는 것 → 그 안에는 안전함과 편안함이 없음

01개념 · 디자인디자인 = 목적·의도를 가지고 공간을 가꾸는 일, 사람-공간-건축-도시-자연-마음을 잇는 작업
  • 우리는 도시·건축을 디자인함 — 자기 집도, 사회적 약자를 위한 공간도
  • 디자인 = 목적·의도를 가지고 대상·공간을 가꾸는 것
  • 사람-공간-건축-도시-자연-마음을 연결하는 작업
02개념 · 가꿈과 돌봄가꿈·돌봄 = 정성을 기울여 보호하며 관심을 두고 지속해서 보살피는 일 ↔ 겉모습만 꾸미는 관리
  • 가꿈 = 손질하고 보살핌(좋은 상태로 꾸려 감) / 돌봄 = 관심 있게 보살핌
  • 공통 의미: 정성을 기울여 보호하며 관심을 두고 지속해서 보살피는 일
  • 관리(배려·공감 없이 최소한의 법적 요건만, 겉모습 꾸미기) ≠ 보살핌 → 안전함·편안함 없음

헷갈리기 쉬운 것

  1. '가꿈'은 관심 있게 보살피는 것, '돌봄'은 식물을 손질하는 것이다뜻이 바뀌었음. 가꿈 = 손질하고 보살핌, 돌봄 = 관심 있게 보살핌(2문단 ①③)
  2. '가꿈'과 '돌봄'의 공통 의미는 겉모습을 보기 좋게 꾸미는 일이다정성을 기울여 보호하며 관심을 두고 지속해서 보살피는 일(2문단 ④). 겉모습 꾸미기는 관리
  3. 최소한의 법적 요건을 갖추면 공간에 안전함과 편안함이 생긴다법적 요건'만' 갖춘 관리에는 안전함·편안함이 없음(2문단 ⑥⑦)

23~4문단문단 탐험: 문제와 사례: 꾸미기보다 배려

문제와 사례: 꾸미기보다 배려

하는 일: 함께 쓰는 공간에서 보살핌이 흐려지는 문제를 지적하고, 사용자를 배려한 실제 사례로 가꿈의 시작을 보여 줌

큰 틀 요약

  • 모두 함께 쓰는 공간(길과 도로·공중화장실·대중교통·공원의 편의 시설)에서 보살핌의 의미가 조금씩 퇴색되어 가는 듯함
  • 꾸미기에 열중한 나머지 정작 제일 중요한 사람에 대한 배려는 뒷전
  • 가꿈의 시작 = 법규에만 맞춘 계획이 아니라 사용자를 배려한 계획
  • 수원 시청 앞 버스 승강장: 고정 의자 → 공간 차지, 휠체어를 사용하는 장애인의 큰 불편, 눈·비도 못 피함 → 자동 접이식 의자 → 공간 확보·더 많은 사람 대기 + 좁은 인도의 통행 문제 해결

문단별로

03문제함께 쓰는 공간에서 보살핌의 의미가 퇴색, 꾸미기에 열중해 사람에 대한 배려는 뒷전
  • 모두 함께 쓰는 공간(길·도로, 공중화장실, 대중교통, 공원 편의 시설)에서 보살핌의 의미가 조금씩 퇴색됨
  • 꾸미기에 열중 → 제일 중요한 사람에 대한 배려는 뒷전
04사례 · 가꿈의 시작사용자를 배려한 계획 = 수원 시청 앞 버스 승강장의 자동 접이식 의자
  • 가꿈의 시작 = 법규에만 맞춘 계획이 아니라 사용자를 배려한 계획
  • 사례: 수원 시청 앞 버스 승강장(조그마한 가꿈)
  • 전: 고정 의자 → 공간 차지 → 휠체어를 사용하는 장애인의 큰 불편, 눈·비도 못 피함
  • 후: 자동 접이식 의자 → 공간 확보·더 많은 사람 대기, 좁은 인도의 통행 문제도 해결

35문단문단 탐험: 주장: 매일 돌보고 가꾸기

주장: 매일 돌보고 가꾸기

하는 일: 공간을 매일 돌보고 가꾸어야 하는 까닭을 아기를 보살피는 일에 빗대고, 소홀했을 때의 결과와 대조해 주장함

큰 틀 요약

  • 배려하여 계획된 공간에서는 어디를 손보아야 하는지, 무엇이 불편한지 알 수 있음
  • 공간은 매일 돌보고 가꾸어야 함 — 아기를 보살피듯 가꾸면 어느새 풍요로운 생활 환경으로 성장(직유)
  • ↔ 사용자를 배제한 형식적인 계획 → 버려지는 위험한 공간, 아무리 좋은 공간도 보살피지 않으면 쓸모없음 → 소홀함은 사회적 약자에게 또 다른 사고를 일으킬 수도 있음
  • 그러므로 사회적 약자를 위한 공간은 조금 더 돌보고, 조금 더 가꾸고, 조금 더 보살펴 안전한 장소로 조성해야 함(반복)

문단별로

  • 배려하여 계획된 공간 → 손볼 곳·불편한 점을 알 수 있음
  • 공간은 매일 돌보고 가꾸어야 함 — 아기를 보살피듯 가꾸면 풍요로운 생활 환경으로 성장
  • ↔ 사용자를 배제한 형식적 계획 → 버려지는 위험한 공간 / 보살피지 않으면 쓸모없음 / 소홀함 → 사회적 약자의 또 다른 사고
  • 그러므로 사회적 약자를 위한 공간은 조금 더 돌보고·가꾸고·보살펴 안전한 장소로

  3. 소홀함은 반드시 사회적 약자에게 사고를 일으킨다사고를 일으킬 '수도' 있음(5문단 ⑥, 가능성)
46~7문단문단 탐험: 결론: 공동체와 조화

결론: 공동체와 조화

하는 일: 주변 공간을 보살피는 일이 공동체로 이어짐을 밝히고, 새것과 기존 것의 조화로 글을 마무리함

큰 틀 요약

  • 주변 공간을 보살피면 → 지역 살림에 관심, 소통할 수 있는 지점을 찾음 → 지나치던 공간에서 새로운 사람과 소통하며 지역을 다시 발견·인식 → 함께 살아가는 공동체의 중요성을 깨달음
  • 새로운 환경을 만드는 것도 중요 + 기존 시설을 돌보고 가꾸는 노력도 중요
  • 새것 계획과 기존 것 돌보기가 조화를 이룰 때 더 좋은 도시 건축 환경이 탄생하고, 사소한 곳에서라도 사회적 약자를 배려하는 공간이 생겨남

문단별로

06결론 · 공동체주변 공간을 보살피면 소통하고 지역을 다시 발견해 공동체의 중요성을 깨달음
  • 주변 공간 보살피기 → 지역 살림에 관심, 소통 지점 발견
  • 지나치던 공간에서 새로운 사람과 소통 → 지역을 다시 발견·인식
  • → 함께 살아가는 공동체의 중요성을 깨달음
07결론 · 조화새것과 기존 것 돌보기가 조화를 이룰 때 더 좋은 도시, 사회적 약자를 배려하는 공간
  • 새 환경 만들기도 중요 + 기존 시설 돌보고 가꾸기도 중요
  • 둘이 조화를 이룰 때 → 더 좋은 도시 건축 환경 + 사소한 곳에서라도 사회적 약자를 배려하는 공간

헷갈리기 쉬운 것

  1. 필자는 새로운 환경을 만드는 일은 필요 없다고 본다새것을 만드는 것'도' 중요·필요하고, 기존 것을 돌보는 노력'도' 중요(7문단 ①②)

관리 ↔ 가꿈·돌봄 (필자의 관점)

  1. 관리 — 필자가 비판하는 쪽가꿈·돌봄 — 필자가 주장하는 쪽
  2. 배려·공감 없이 최소한의 법적 요건만 갖춘 계획2문단↔정성을 기울여 보호하며 관심을 두고 지속해서 보살핌2문단
  3. 겉모습만 꾸밈, 꾸미기에 열중2·3문단↔사용자를 배려한 계획 — 수원 버스 승강장 자동 접이식 의자4문단
  4. 법규에만 맞춘 계획, 사용자를 배제한 형식적 계획4·5문단↔공간을 매일 돌보고 가꾸기, 아기를 보살피듯5문단
  5. → 안전함·편안함 없음, 버려지는 위험한 공간, 사회적 약자의 또 다른 사고2·5문단↔→ 풍요로운 생활 환경, 안전한 장소, 공동체, 사회적 약자를 배려하는 공간5~7문단

필자의 가치관 (교과서 학습 활동 2)

◯ 필자의 가치관관심배려가꿈돌봄보살핌안전함편안함

✕ 필자가 비판하는 쪽법규에만 맞춤겉모습소홀함형식적

  • 사용자를 배려하여 공간을 계획해야 한다. (교과서 예시)
  • 공간은 관심을 두고 매일 돌보고 가꾸어야 한다.
  • 사회적 약자를 위한 공간은 조금 더 돌보고 가꾸고 보살펴 안전한 장소로 조성해야 한다.
  • 새로운 것을 만드는 것만큼 기존의 것을 돌보고 가꾸어 조화를 이루는 것도 중요하다.

글의 짜임 (전개 방식)

  1. 디자인의 의미를 정의하고, 디자인이 잇는 대상(사람-공간-건축-도시-자연-마음)을 열거함 (1문단)
  2. 가꿈과 돌봄을 정의해 공통 의미를 이끌어 낸 뒤, 단순한 관리와 대조함 (2문단)
  3. 함께 쓰는 공간을 열거하며 보살핌의 의미가 퇴색되는 문제를 지적함 (3문단)
  4. '법규에만'과 '사용자를 배려'를 대조하고, 수원 시청 앞 버스 승강장의 실제 사례를 문제-해결 구조로 보임 — 옆 사진 (4문단)
  5. 당위 표현('가꾸어야 한다')으로 주장하고, '아기를 보살피듯'(직유)과 형식적 계획을 대조한 뒤 '조금 더'를 반복해 강조함 (5문단)
  6. 주변 공간을 보살피는 일이 공동체로 이어지는 과정을 차례로 보이고, 새것과 기존 것의 조화로 마무리함 (6~7문단)

「공존, 함께 산다는 것」 가~다 속의 '나' (교과서 학습 활동 4)

글의 영역
인문 분야 · 중수필
특징
실제 사례(수원 시청 앞 버스 승강장)와 사진으로 필자의 생각을 쉽게 이해하게 함
공존에 대한 관점
사용자를 배려한 도시 공간을 디자인하여 사회적 약자와의 공존을 추구함
글쓰기 방법
실제 사례를 제시하여 공동체를 위한 도시 건축 디자인에 대한 필자의 가치관을 독자가 쉽게 이해할 수 있도록 함
