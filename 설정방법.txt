독서와 작문 통합 수업 사이트 (2-2 줄서기 · 3-1 사랑의 기술 · 3-2 사진의 타이밍 · 5-2 문화를 담은 건축물 · 6-1 재생과 공존 · 6-2 함께 돌보고 가꾸어야 할 도시 공간 · 6-3 고령자를 위한 읽기) — 처음 한 번 설정하기 (15분쯤)

이 폴더 하나를 Netlify에 올리면 주소 하나로 일곱 수업을 다 씁니다.
  · 첫 화면(단원 고르기): https://○○○.netlify.app
  · 지우:   첫 화면 주소만 열어 두면 끝(로그인 없음) → 선생님이 수업을 열면 그 단원 화면으로 저절로 넘어가 선생님 화면을 그대로 따라감
  · 선생님: 첫 화면 주소 끝에 ?t → 단원의 [문단 탐험]을 누르면 선생님 화면(구글 로그인)으로 열림
            바로 가기 예) https://○○○.netlify.app/3-2/?t
  · 단원 주소: /2-2/ · /3-1/ · /3-2/ · /5-2/ · /6-1/ · /6-2/ · /6-3/   혼자 읽기 /3-2/solo.html · 큰 틀 정리 /3-2/summary.html
  ※ 선생님이 다른 단원으로 옮기면 지우 화면도 그 단원으로 따라 넘어가요(넘어갈 때마다 지우가 [전체화면으로 보기]를 한 번 눌러야 해요).
  ※ 선생님이 수업 탭을 모두 닫으면 지우 화면은 그 자리에 멈추고, 첫 화면은 다시 '기다리는 중'이 돼요.

단원별로 따로 만들었던 수업사이트 폴더 일곱 개(줄서기·사랑의기술·사진의타이밍·문화를담은건축물·재생과공존·도시공간·고령자읽기) 대신 이 폴더 하나만 올리면 돼요.
설정값은 맨 위 config.js 하나만 채우면 일곱 수업에 다 적용돼요(단원 폴더 안에는 config.js가 없어요).

[A] Firebase (선생님 구글 계정으로, 무료)
 1. console.firebase.google.com → 프로젝트 추가 → 이름 입력(예: jiwoo-class) → Google 애널리틱스는 꺼도 됨 → 만들기
 2. 왼쪽 메뉴 [빌드 → Authentication] → 시작하기 → [로그인 방법] 탭
      · Google → 사용 설정(지원 이메일 고르기) → 저장
      · 익명(Anonymous) → 사용 설정 → 저장
 3. [빌드 → Realtime Database] → 데이터베이스 만들기 → 위치: 싱가포르(asia-southeast1) → 잠금 모드로 시작 → 사용 설정
 4. 같은 화면 [규칙] 탭 → 안의 내용을 모두 지우고 이 폴더의 database.rules.json 내용을 붙여 넣기
      → '선생님구글메일@gmail.com'(4군데)를 모두 선생님이 로그인할 구글 메일로 고치기 → 게시
      ※ 이 규칙 하나로 일곱 수업이 다 돼요. 수업마다 기록이 다른 자리에 저장돼서 섞이지 않아요.
 5. 톱니바퀴(프로젝트 설정) → 일반 → 아래쪽 [내 앱]에서 웹 아이콘(</>) → 앱 닉네임 입력 → 앱 등록
      → 화면에 나오는 firebaseConfig 의 중괄호 { } 안 내용을 복사 → 이 폴더 맨 위 config.js 의 중괄호 안에 붙여 넣고 저장
      ※ databaseURL 줄이 꼭 있어야 해요. 없으면 Realtime Database 화면 맨 위 주소(https://…firebasedatabase.app)를
        databaseURL: "그 주소", 형태로 직접 넣으세요.

[B] Netlify
 6. app.netlify.com 에 로그인 → Sites(사이트) 화면의 끌어다 놓기 칸(또는 app.netlify.com/drop)에 이 폴더를 통째로 끌어다 놓기
      → 잠시 뒤 https://○○○.netlify.app 주소가 생김 (사이트 설정에서 이름을 바꿀 수 있음)
 7. Firebase로 돌아가 [Authentication → 설정 → 승인된 도메인] → 도메인 추가 → ○○○.netlify.app (https:// 없이)

[C] 확인
 8. 선생님 컴퓨터에서 https://○○○.netlify.app/?t → 3-2단원 [문단 탐험] → Google로 로그인 → 위쪽에 '수업 공유 중'이 보이면 성공
 9. 다른 창(또는 휴대폰)에서 https://○○○.netlify.app (첫 화면) → 3-2단원 화면으로 저절로 넘어가 선생님 화면을 따라오는지 확인

[단원별 사이트를 이미 설정해 두었다면 — 3분]
 같은 Firebase 프로젝트를 그대로 써요. 그 사이트 폴더의 config.js 를 이 폴더 맨 위에 복사해 덮어쓰고, 6·7번만 하면 돼요. 규칙은 그대로 두세요.

고칠 때: 폴더 안 파일을 바꾼 뒤 Netlify 사이트의 [Deploys] 화면에 폴더를 다시 끌어다 놓으면 같은 주소로 바뀝니다.
알아 둘 점: 주소를 아는 사람은 누구나 수업 화면을 볼 수 있어요(조작은 규칙에 적은 선생님 메일만). 학생 상태(전체화면·탭 이동)는 선생님만 봐요.
